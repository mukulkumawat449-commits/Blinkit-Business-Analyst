# Blinkit-Business-Analyst
BlinkIT Grocery Sales Analysis – Power BI Dashboard
Built an interactive Power BI dashboard on BlinkIT grocery data to analyze sales performance across item categories, outlet types, sizes, and locations. Created DAX measures (Total Sales, Average Sales, Item Count, Average Rating) and designed KPI cards, donut, bar, line, and funnel charts with a dynamic metric selector and slicers (Item Type, Outlet Size, Outlet Location) for business insights.

# BlinkIT Grocery Sales Analysis – Power BI Dashboard

## Overview
Interactive Power BI dashboard to analyze BlinkIT grocery sales and customer ratings across products and outlets.

## Key Features
- KPI cards: Total Sales, Average Sales, No. of Items, Average Rating
- Sales by Item Fat Content (Donut chart)
- Sales by Item Type (Bar chart)
- Sales trend by Outlet Establishment Year (Line chart)
- Sales by Outlet Size and Outlet Location Type (Donut, Funnel, Clustered Bar)
- Outlet Type summary table (matrix)
- Dynamic metric switching using a slicer
- Filters: Item Type, Outlet Size, Outlet Location

## Tools Used
Power BI, DAX, Power Query, Microsoft Excel

## Dataset
BlinkIT Grocery Data (Excel) – item type, fat content, visibility, weight, outlet details, sales, and ratings.
